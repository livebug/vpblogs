# 金融监管周报

> 每周一自动汇总最新金融监管信息，按周归档。关注**制度更新、监管新闻、处罚通报**，并单列**EAST、一表通、1104、人行统计**等监管报送口径的变化与影响。

## 栏目说明

- **频率**：每周一 09:00 更新，覆盖上一个完整自然周（周一至周日）。
- **结构**：一期速览 → 监管制度更新 → 金融科技动态 → 监管报送专题 → 方向分析与行动清单 → 数据图表与来源。
- **来源**：监管总局、人民银行、证监会、外汇局公示与权威媒体原文，文末附完整链接。
- **口径**：只写可核实信息；处罚金额区分“罚单金额”与“罚没总额”，不做无依据加总；图表数据与正文表格一致。
- **导出**：文章页右下角「导出」按钮，按 A4 版式打印或另存为 PDF（已适配图表、表格分页，外部链接会自动补印 URL）。
